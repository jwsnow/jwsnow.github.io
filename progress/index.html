Static, local, portable

Collect student practice progress without a server.

Import student progress JSON files from the practice sites. This dashboard stores the current class records in this browser, replaces older records when a newer export for the same student and site is imported, and recomputes class-wide strengths and weaknesses.

Import student progress

Select one or many progress files. Student name is required in exported files; Student ID is optional.

Move or back up this dashboard

Export instructor backup downloads everything currently stored here as one JSON file. To restore on another browser or machine, choose how the backup should be applied, then use Restore backup above.

A backup file contains all stored students and all of their imported site records. It does not contain any server credentials because this dashboard does not use a server.

Storage and privacy

All imported information is stored in this browser’s local storage. Nothing is uploaded by this dashboard. Clearing this browser’s site data can erase the dashboard, so use Export instructor backup regularly if you want a portable copy.
