# TExES Mathematics 7–12 (235) Practice Center

A self-contained static website for secondary mathematics certification preparation.

## Included

- Five fixed 100-question full-length forms and a randomized form
- Four fixed 12-question quizzes plus randomized practice for each of the 21 competencies
- Coverage of all six official domains, including mathematical learning, instruction, and assessment
- Explanations for every answer
- Diagnostic reports by official domain and by competency
- Direct links from weak competencies to targeted practice
- Timers, flags, navigation, printable reports, and browser-local score history

## Hosting

Upload the entire folder to any ordinary static web host. Open `index.html` as the entry page.

## Important limitation

This is an independent, original practice resource. It is aligned to the publicly available exam framework but has not been field-tested or psychometrically calibrated. Raw practice percentages are not official TExES scaled scores.
