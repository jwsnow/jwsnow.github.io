# Real Analysis Practice Center

A separate static website designed to accompany *An Introduction to Real Analysis* by John W. Snow.

## Scope
- Begins with Section 1.2.
- Includes all sections through 6.5.
- Section 1.6 is treated as the cumulative Chapter 1 homework center.
- Later section pages combine note concepts, theorem hypotheses/conclusions, proof-strategy choices, calculations, examples, counterexamples, and homework-style reinforcement.
- Sections whose exercises are grouped elsewhere in the notes (4.1-4.3 and 5.1-5.5) explicitly connect to those grouped exercises.

## Use
Upload the entire folder to a static web host and link to `index.html`.

The site uses MathJax from a public CDN. All quiz data, scoring, and progress storage are client-side. Completed attempts are stored in the current browser's localStorage. Unfinished answers are not saved.

## Content disclaimer
The questions are original reinforcement items aligned to the organization and focus of the uploaded notes. They are not copied answer keys and do not replace written proof assignments.

## Counts
- 40 section centers
- 469 question-bank items
- 5 quiz modes per section
- chapter review forms and cumulative review
