PDF tools

ExportSelect one or more documents above

One checked document exports as a PDF. Two or more checked documents are exported together in one ZIP; each PDF keeps its own current page order and edits.

CompressSelect one or more documents above

Preserve mode keeps PDF text/vector pages structural and recompresses imported image pages. Existing raster images embedded inside an opened PDF are left intact in this first structure-preserving pass. Rasterize is explicit because it turns every output page into a JPEG image and removes selectable text.

ExtractSelected pages from the active document

SplitSplit the active document

Split operates on the active document. Multiple output PDFs are packaged into one ZIP for a single save/share operation.

Within a line, use commas for additional pages/ranges, for example 1-4,8,11-13. Page numbers refer to the current Pages order.

CombineSelect two or more documents above

The checked documents appear below. Arrange their combine order without changing the general Open documents list. Combining creates a new working document and leaves the originals unchanged.

Library management

TrashNo documents in Trash

Documents moved to Trash are removed from the active workspace but remain recoverable until permanently deleted.

Library backup & exportPDF archive and editable restore

Export a conventional PDF copy of the whole active Library, or create a complete editable backup that can restore PDF Workbench on this or another device.

The PDF archive preserves the Library folder/subfolder structure and includes saved templates as one-page PDFs. Trash is omitted. Editable backups are written as .pwbbackup.zip. Restore replaces the current Library; Import backup as folder keeps the current Library and adds the backup as a new subtree.

Storage & resetLibrary recovery and development reset tools

The Library is stored separately from the service-worker app cache. Normal PDF Workbench updates should not erase it.

Persistent documents, folders/subfolders, direct-to-folder import, folder ZIP import/export, folder-tree Trash/recovery, rename/duplicate/move, thumbnails, templates, whole-Library PDF ZIP export, and editable backup/restore/import-as-subtree are available now. Favorites/search/sort remain lower priority; schema/recovery hardening and PDF link/outline preservation still need dedicated testing.

Page size / canvas

Content

Fit & center: existing page content keeps its aspect ratio and is scaled proportionally to fit inside the new page. No cropping is performed. Setting an exact Page size clears earlier Crop / margins adjustments; apply Crop / margins afterward when both are desired. The source file is unchanged; use Undo to reverse the operation.

Crop / margins

Current page

Margins add white canvas without scaling the current page. Crop moves the page boundary inward without scaling the content. Values apply to the edges as currently viewed, even on rotated pages. Repeated operations accumulate and can be reversed with Undo.

Copy selected pages

Copies keep their original page size, rotation, and content. The source document is not changed.
