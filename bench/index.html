Files & output

Document-level operations live here. Opening files still keeps them separate; combining is always an explicit operation.

Export current document

Export the current document exactly as it is organized in PDF Workbench.

Extract selected pages

Select pages in Pages, then save just those pages as a new PDF.

Split current document

Split outputs are saved directly. When a split creates multiple PDFs, PDF Workbench packages them into one ZIP for a single save/share operation.

Within a line, use commas for additional pages/ranges, for example 1-4,8,11-13. Page numbers refer to the current Pages order.

Combine open documents

Choose two or more open documents and arrange their order. This creates a new working document; it does not alter the originals.

Page-size normalization, image assembly, compression, closing documents, and the persistent Library/folder system remain later roadmap items.
