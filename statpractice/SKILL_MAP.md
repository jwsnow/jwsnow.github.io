# Statistics Practice Center — Skill Map

The site contains **12 diagnostic exams**, **56 focused skills**, and **1,764 questions**.

Each diagnostic has four fixed forms (A–D) and a Random option. Each focused skill has three fixed versions and a Random option. Fixed versions are nonoverlapping by question ID, and fixed skill versions contain no exact repeated stems.
