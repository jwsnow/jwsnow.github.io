# Texas Core Subjects Diagnostic & Practice Portal

A self-contained static website linking four subject centers:

- Mathematics
- Science
- Social Studies
- English Language Arts and Reading

## Included exams

### Mathematics
- Core Subjects EC–6 Mathematics (902)
- Core Subjects 4–8 Mathematics (807)
- Mathematics 4–8 (115)
- ACCUPLACER Arithmetic, QAS, and AAF

### Science
- Core Subjects EC–6 Science (904)
- Core Subjects 4–8 Science (809)
- Science 4–8 (116)

### Social Studies
- Core Subjects EC–6 Social Studies (903)
- Core Subjects 4–8 Social Studies (808)
- Social Studies 4–8 (118)

### ELAR and Reading
- Core Subjects EC–6 ELAR (901)
- Core Subjects 4–8 ELAR (806)
- English Language Arts and Reading 4–8 (217)
- Science of Teaching Reading (293)

## Features

- Four or five fixed full forms plus a random form for every exam
- Three fixed versions plus random practice for every component area
- Correct-answer explanations for every selected-response question
- Ranked weakness reports and direct targeted-practice links
- Timers, flags, numbered navigation, printable reports, and browser-local history
- Four self-assessed constructed-response writing labs for ELAR 4–8 and STR
- Responsive layouts for desktops, tablets, and phones
- No build process, database, account, PHP, or server-side code

## Hosting

Upload the entire folder without changing its directory structure. Open `index.html` for the four-subject portal.

For local testing:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000/` from the portal folder.

## Question design and scoring

The questions are original and were written to align with public Pearson/TExES frameworks. Published sample questions were not copied. Scores are raw diagnostic percentages, not official scaled scores or validated passing predictions.
