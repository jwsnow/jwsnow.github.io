    Page and file sizing

    • One image is placed on each PDF page.
    • Portrait images use 8.5 × 11 inch pages; landscape images use 11 × 8.5 inch pages.
    • Images are scaled proportionally and are never cropped.
    • Transparent areas are placed on a white background.
    • Animated images contribute their first displayed frame.
    Processing occurs locally in the browser. The page loads open-source JavaScript libraries from a content-delivery network.
