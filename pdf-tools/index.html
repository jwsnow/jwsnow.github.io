Private, browser-based utilities

Prepare files for online submission.

These tools run in the student’s browser. Files are processed locally and are not uploaded to a server.

Resize and compress a PDF

Converts every page to a letter-size page and reduces the finished PDF to no more than 10 MB.

Open PDF tool

Combine images into a PDF

Accepts multiple PNG, JPEG, HEIC, HEIF, and other browser-readable images and creates one letter-size PDF under 10 MB.

Open image tool

Important limitation

The PDF resizing tool flattens each page into an image. This is what makes dependable size reduction possible in a browser, but selectable text, hyperlinks, form fields, annotations, and accessibility tags are not retained.

All file processing occurs on the local device.
